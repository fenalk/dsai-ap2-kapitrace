minor — src/frontend/src/lib/indicator.ts: Heurística de IP por ':' pode classificar entradas inválidas como IP
detectIndicatorType retorna 'ip' para qualquer valor que contenha ':' (fora de URL com esquema). Isso cobre IPv6, mas também classifica entradas como 'foo:bar' ou 'exemplo.com:8080' como IP. A validação final fica no backend, então não há risco de segurança, mas o seletor pode mostrar 'IP' para algo que o usuário digitou como domínio com porta. Vale considerar restringir a heurística a padrões de IPv6 ou documentar a decisão na SPEC.
minor — src/frontend/src/app/(app)/lookup/page.tsx: Estado 'checking' desabilita o botão de adicionar à watchlist
Enquanto o GET /api/watchlist está em andamento, o botão aparece com loading e fica desabilitado. Se a chamada demorar, o usuário não consegue adicionar imediatamente. O E2E já espera o estado 'absent' antes de clicar, então o comportamento é intencional, mas um timeout explícito na chamada de watchlist (ou permitir adicionar mesmo durante a checagem) tornaria a UX mais robusta.
info — src/frontend/src/lib/recent-lookups.ts: Estado de módulo com subscribeSession no import
O módulo registra um listener de sessão no momento do import e mantém estado global em memória. Isso é consistente com lib/session.ts e coberto por testes, mas vale garantir que o listener não acumule em hot reload de desenvolvimento (o Set de listeners é limpo por unsubscribe, então o risco é baixo).
