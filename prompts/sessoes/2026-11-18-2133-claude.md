## Como liberar a ação bloqueada (apagar o commit `9c0ec73`)

Quem bloqueou foi o classificador do modo automático do Claude Code, porque a ação reescreve o histórico de uma branch publicada. Há três formas de autorizar:

**a) Rodar você mesma no terminal (o mais simples).** A partir do commit atual (`49858d3`), os comandos seriam:
```bash
git rebase --onto 854cbc7 49858d3
git push --force-with-lease origin HEAD
```
O resultado é a branch só com o commit `854cbc7`, sem os dois commits do registro. O arquivo continua no seu disco, porque não está rastreado.

**b) Liberar no Claude Code só para este projeto.** Basta adicionar uma regra de permissão em `.claude/settings.local.json`, que não é versionado:
```json
{ "permissions": { "allow": ["Bash(git push --force-with-lease:*)"] } }
```
Também dá para fazer pelo comando `/permissions`. Com a regra, eu passo a poder fazer esse tipo de push sozinho.

**c) Trocar o modo de permissão.** Saindo do modo automático para o modo padrão, eu peço confirmação a cada ação, em vez de o classificador decidir. Aí você aprova só este force-push.

Para uma ação isolada, a (a) ou a (c) bastam. A (b) deixa a permissão ligada para as próximas vezes.
